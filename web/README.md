# Frequency

あなたが実際に使う英語だけを、毎日20秒から。

教科書の英語ではなく、あなたの仕事・趣味・生活の英語を教材にするローカル学習アプリです。

## 起動

**「Frequency を起動.cmd」をダブルクリック**してください。
`http://localhost:8777` でブラウザが開きます。

終了するときは、開いた黒い画面で `Ctrl + C` を押してください。

> `index.html` を直接ダブルクリックしても動きますが、その場合は保存容量が
> 小さくなり、オフライン機能も使えません。通常は上記の .cmd から起動してください。

## 使い方

1. **プロンプトをコピー** — 普段お使いのAI（ChatGPT / Claude / Geminiなど）に貼り付けます
2. **AIの回答を貼り付け** — あなたの学習分野が自動で作られます
3. **分野を選ぶ** — まずは重要な1〜2分野から
4. **教材プロンプトをコピー → 回答を貼り付け** — 表現と英文が取り込まれます
5. **学習開始** — 1問だけでも連続記録は続きます

分野は後からいつでも追加できます（設定 → 教材）。

## 重要な性質

- **AI APIを使いません。** 教材はあなた自身のAIに作ってもらい、コピー＆ペーストで取り込みます。アプリから外部への通信は一切ありません。
- **データはこの端末だけに保存されます**（IndexedDB）。クラウド同期はありません。
- **バックアップは手動です。** クラウドに控えがないため、設定画面から定期的に「データをエクスポート」してください。
- **オフラインで学習できます。** 新しい教材を作るときだけ、AIを使うためにインターネットが必要です。

## 難易度

設定画面で3段階から選べます（初期値は「むずかしい」）。

| | 読み上げ | 聞き直し | ダミーの単語 |
|---|---|---|---|
| やさしい | 0.85倍 | 無制限 | 3語 |
| ふつう | 0.95倍 | 4回まで | 6語 |
| むずかしい | 等倍 | 2回まで | 10語 |

聞き取り問題では、空欄のある英文と日本語訳を必ず表示します。
どの表現を答えるべきかが分からないと問題として成立しないためです。
難しさは、読み上げの速さ・聞き直せる回数・紛らわしいダミー単語の多さで調整します。

## スマホでの操作

聞き取りは**タップして単語を組み立てる**方式が初期設定です。スマホで英語キーボードを打つ必要がありません。
候補にはあなたの教材から選んだ紛らわしい単語が混ざります。
キーボード入力に切り替えることもできます（問題画面のリンク、または設定）。

## 取り込んだデータの初期化

設定 →「取り込んだデータの初期化」から、消す範囲を選べます。
実行前に必ず「何件消えるか」を表示し、確認してから削除します。

| 操作 | 消えるもの | 残るもの |
|---|---|---|
| この分野の教材を削除 | その分野の表現・英文・問題・復習予定 | 分野の枠、他分野、記録 |
| この分野ごと削除 | 上記＋分野そのもの | 他分野、記録 |
| 教材をすべて削除 | 全分野の教材と復習予定 | 分野一覧、ストリーク、XP、履歴 |
| 学習記録だけリセット | 復習予定・履歴・ストリーク・XP | 教材すべて |
| プロフィールを取り込み直す | 何も消えません | すべて（分野が更新・追加されます） |
| プロフィールと分野を初期化 | プロフィール・分野・教材 | ストリーク・XP・回答履歴・設定 |
| すべて初期化 | **すべて**（設定も含む） | なし（初回起動の状態） |

プロフィール（英語レベル・役割・学習分野）を取り直したいときは「プロフィールを取り込み直す」から、
最初のプロンプトをもう一度実行できます。既存の教材は消えません。

**「この分野の教材を削除」は分野の枠を残す**ので、AIに作り直してもらった教材をすぐ貼り直せます。
複数の分野で使われている表現は、削除した分野との紐づけを外すだけで、
表現そのものと学習状況は残ります。

## 問題の種類

| 形式 | 内容 |
|---|---|
| 言い換えリスニング | 聞こえた英文の趣旨に最も近い**英文**はどれか |
| 内容リスニング | 聞こえた内容に最も近い**日本語**はどれか |
| ディクテーション | 空欄の表現をタップして組み立てる |
| 並べ替え | 単語を並べ替えて英文を復元する |

上の2つは、**肯定と否定・主体・時制・条件・強さ**だけが違う紛らわしい選択肢を
AIに作らせています。細部まで聞き取らないと選べません。
「言い換え」は選択肢がすべて英文なので、読むだけでも語彙に触れられます。
出題比率はこの2つを合わせて約6割です。

## 学習の仕組み

- **間隔反復** — 正解するたび復習間隔が `1 → 3 → 7 → 16 → 35日` と伸び、間違えると翌日に戻ります
- **習得の判定** — 4択だけで正解しても「習得ずみ」にはなりません。ディクテーションか並べ替えで正解して初めて上位に進みます
- **1問モード** — 1問でも学習日として記録され、SRS・XP・連続記録すべてが通常どおり更新されます
- **学習日** — その日に1問でも「回答」すれば学習日。正解する必要はありません
- **ストリークフリーズ** — 休んだ日を1日ぶん肩代わりします。足りない場合のみ記録が途切れます（最高記録は残ります）

## ファイル構成

```
index.html              画面の骨組み
css/app.css             スタイル
js/util.js              日付・文字列・配列のユーティリティ
js/db.js                IndexedDB（使えない場合はlocalStorageに自動切替）
js/prompts.js           AI用プロンプト4種（バージョン管理付き）
js/importer.js          取り込み: 抽出 → 検証 → 正規化 → 重複排除 → 保存
js/questions.js         英文から3形式の問題を生成
js/srs.js               間隔反復と習熟度
js/progress.js          連続記録・XP・報酬
js/speech.js            読み上げ（未対応環境でも壊れません）
js/session.js           出題の組み立てと回答の記録
js/backup.js            エクスポート／インポート
js/ui.js                描画
js/app.js               画面遷移とイベント
sw.js                   オフライン用キャッシュ
server.js               ローカルサーバー（依存パッケージなし）
legacy-prototype.html   旧プロトタイプ（参考用）
```

## プライバシー

学習データはこの端末に保存され、アプリから外部サーバーへ送信されません。
ただし、あなたがAIに入力した内容の扱いは、そのAIサービスのポリシーに従います。
