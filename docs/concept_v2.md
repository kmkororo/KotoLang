# KotoLang 構想メモ

英語の聞き取りアプリ。個人開発、Android、オフライン専用。
このメモは、アイデアの壁打ち相手にそのまま渡せるように書いてあります。

---

## 1. 一行で

機械が訳せる時代に、訳さずに分かるための、聞き取り専用の育成アプリ。

---

## 2. なぜ作るのか

### 前提

AI によるリアルタイム翻訳は、遠からず実用水準に達する。
マニュアルを読む、メールを書く、案内を理解する。この用途で英語を学ぶ理由は、
これから急速に弱くなる。実用目的だけを掲げた英語学習アプリは存在理由を失う。

### それでも残るもの

翻訳が肩代わりできるのは「情報を受け取ること」で、代われないのは「その場にいること」。

- **間合い**。人の会話は、相手が言い終わる前に次を組み立てて始まる。その隙間はコンマ数秒。
  翻訳が挟まると必ず壊れる。遅延がゼロになっても壊れる。訳された言葉は本人の声ではない。
  冗談も、割り込みも、相槌も、機械を通すと別の行為になる。
- **信頼の合図**。相手の言葉を話すことは、その相手に時間を投資した証明になる。
  機械はその投資を不要にするので、証明にもならない。翻訳が安くなるほど、
  自分で話せることの価値は上がる。
- **聞こえてくるもの**。翻訳は「向ける」必要がある。誰も頼まないから訳されない情報が大量にある。
  隣の席の雑談、会議の空気、通りすがりの一言。仕事でも生活でも、大事な情報はここを流れる。
- **端末が使えない場面**。騒がしい店、廊下での立ち話、急いでいるとき、電池切れ。
  重要な瞬間ほど段取りできない。
- **精度が要る場所**。翻訳は必ず何かを落とす。落ちるのは技術用語、法律、皮肉、含み。
  つまり正確さが一番要る場所。

### だから何を鍛えるか

**自然な速さで、初回で、文字なしで、会話についていく力。** これ一点。

読解も作文も語彙暗記もやらない。それらは機械が最初に食べる領域で、
手を広げると残る側の強みが薄まる。

---

## 3. 誰のために

- 英語を仕事や生活で「その場で」使う必要がある人。
- 教材として与えられた文章ではなく、自分の現実に近い場面で練習したい人。
- 買い切りで、広告も課金圧もない道具を求める人。

---

## 4. 制約（設計の前提として動かさない）

- **オフライン専用**。ネットワーク通信を一切しない。
- **権限ゼロ**。マイク、通知、位置情報、ストレージ、どれも要求しない。
- **アカウントなし**。ログインもクラウド同期もない。
- **AI の API キーをアプリに持たない**。生成はユーザー自身の AI（ChatGPT、Claude、Gemini 等）に
  プロンプトをコピペして行い、返ってきた JSON を貼り付けて取り込む。
- **広告・分析・課金導線なし**。将来的には買い切り。
- **UI は10言語**。学習対象は常に英語。
- データは全て端末内。外に出るのは、ユーザー自身がコピーした文だけ。

この制約は不便ではなく特徴として扱う。「何も送らない」ことが売りになる。

## 5. いまの仕組み（実装済み）

### コンテンツ

- 単位は **“会話”**（内部名 scene）。ひとつの“会話”は2往復。
- 各往復は「相手の台詞（音声）→ 何を言ったか（3択）→ どう返すか（3択）」。
- 選択肢は全て英語。日本語訳は答えた後にだけ出る（英語脳を保つため）。
- 音声は端末の TTS。地域を選ぶと、その地域の声だけを使う。
- 内蔵の見本が30本。それ以外はユーザーの AI が生成したもの。

### 分野

- 見本用の4分野（仕事・旅行・学校・日常）＋ AI がプロフィールから読み取った分野。
- 分野はプロフィール由来のみ。自由入力で作ることはできない。
- 最初の3分野は無償で開ける。以後は通貨で解禁。

### 初回の流れ

言語選択 → 4ステップの全体図 → ①年代と関心 → ②AI にプロフィールを作らせる →
③分野を3つ選ぶ → ④AI に“会話”を作らせる → ホーム。

AI とのやりとりは2画面に分かれている。プロンプトをコピーする画面と、
返答を貼る画面。AI から戻ってきたとき、目の前にあるボタンが「貼る」だけになるように。

### 育成

- **木が1本**。分野ごとに1本の大枝。見本の枝は低く短く、自分専用の枝が樹冠。
- 解いた量で幹が太り、段階が6つある。
- 花は自分専用の“会話”で返答に正解したとき。実は全問正解したとき。
- ホームの背景として常に見えている。

### 通貨と報酬

- 正解すると通貨が入る。要旨の正解より返答の正解の方が多い。
- 通貨は分野の解禁と、“会話”の追加生成に使う。
- 連続日数（太陽の印）、お休み券、コンボ表示、音だけで解いた連続記録。
- 正解すると葉が1枚、選んだ行から上部の通貨表示へ飛ぶ。

### 復習

- 間違えた往復は翌日と3日後に再出題される。
- 復習は通常の“会話”の前に混ざって出る。

### 記録

- 理解（要旨）と返答の正答率、全期間と直近7日。
- 連続日数、最高記録、解いた“会話”数、音だけの連続、最長の連続正解。
- 直近28日のヒートマップ。
- “会話”の一覧。

### 設定

表示、音声（読み上げ速度、声、場面ごとに声を変える）、振動、あなたのこと・分野、
バックアップの書き出しと取り込み、削除とやり直し。

## 6. これからの方向（決定済み）

### 6-1. 問題形式を作り替える

いまの形式は、判定基準「自然な速さで、初回で、文字なしで分かったか」に照らすと
測定を汚している。

**弱点**

- 台詞の後に英文を3つ読む。その数秒は読解であって聞き取りではない。
  しかも読んでいる間に音の記憶を反芻できる。
- 読むだけで不自然な選択肢を消去できる。分かったのか絞れただけなのかが区別できない。
- ひとつの“会話”に決断が4回、そのたびにパネルと「次へ」。会話ではなく問題用紙の形。
- 聞き逃したまま進めない。実際は聞き逃しても会話は続き、後から辻褄を合わせる。

**新しい形式**

原則：答えは「その場で実際にすること」であるべきで、時計を止めてはいけない。

1. **選択肢を台詞の前に出す**。3つの返答を先に読ませ、読み終えてから台詞を一度だけ流す。
   決断から読解の時間が消え、純粋な聞き取りだけが残る。
2. **分岐を一語にする**。要旨の言い換えを選ばせる代わりに、意味が割れる一語を突く。
   三時か四時か。行くのか行かないのか。二択なので即答でき、誤答の理由とも一致する。
3. **会話を止めない**。台詞が流れ、返す番になったら選択肢が出て短い窓が開く。
   間に合わなければ相手が先に進み、聞き逃したことが会話の中で分かる。
4. **難しさは音に付ける**。選択肢を難しくするのではなく、速度、雑音、訛り、声の重なりを上げる。
5. **自分宛てでない会話を聞く**。二人の話を横で聞いて、何が決まったのかを拾う。
   翻訳を向けようと思いつかない領域なので代替されない。

まとめると **選択肢を先に出した、一語分岐の、止まらない会話**。
ひとつの“会話”が一分を切る。

### 6-2. 育成ゲームの層を入れる

木を記録から**装置**に変える。

```
答える → 木が育つ → 実がなる → 収穫する → 種をまく → 環境が厳しくなる → 実が増える
```

- **実**。収穫して貯めるもの。分野を開くのにも使う。
- **種**。実を払ってまくもの。まくと環境が厳しくなる。
- 実の中に種があり、まいた種が実をつける。自然の順序のまま。

一問あたりの実は、**木の大きさ × まいた種の厳しさ** で決まる。
どちらも実際に解いて手に入れたものなので、待つだけで増える部分がない。

### 6-3. アップグレード＝難易度

**買うと楽になるのではなく、買うと難しくなる。** その分だけ多くもらえる。

| 買うもの | 効果 | 学習上の意味 |
|---|---|---|
| 訳を完全に消す | 獲得 +50% | 日本語を経由しない |
| 再生 1.2倍 | 獲得 +30% | 自然な速さに寄せる |
| 雑音を入れる | 獲得 +40% | 端末が使えない状況 |
| 一度しか聞けない | 獲得 +60% | 初回で捉える |
| 訛りを混ぜる | 獲得 +40% | 相手を選ばない |

重ねられる。全部入れた人は一回の正解で何倍も得るが、本当に難しいことをしているから。
上げすぎて解けなくなったら下げられる。下げると倍率も下がるので、
自分にちょうどいい負荷を探す遊びになる。

段の種類は4つ混ぜる。

- **買う**（難易度のアップグレード）
- **達成**（探して見つける形。買えないので上手くなった証明になる）
- **育つ**（木の段階。時間ではなく解いた量で進む）
- **開く**（分野。一番大きな段）

段の密度は序盤ほど詰める。最初の“会話”を解き終わる前にひとつ目が買えるくらい。

### 6-4. 続けさせる仕掛け

「いつの間にかずっとやっていた」を作る。原因は具体的にある。

- **区切りをなくす**。決断の場所は、やめる場所。起動して一タップで音が始まる。
- **一決断一タップ**。「決定」と「次へ」の二段を廃し、タップで即確定、短い取り消し窓。
- **次を前の余韻に重ねる**。報酬の演出が終わる前に次の台詞を鳴らす。
- **残り数を見せない**。「1 / 2」と出ると人は2で止まる。見せるのは貯まったものだけ。
- **木を背景で育てる**。ごほうびを見に行く画面にしない。
- **途中から正確に戻る**。“会話”の途中、台詞の途中まで含めて再開する。
- **開いたまま終わる**。やめる直前に次の“会話”の一行目を鳴らし始める。
- **枝に実を残す**。未収穫の実が、放置収入なしで「山が待っている」感覚を作る。

## 7. やらないこと

- **放置収入**。寝ている間に通貨が増えたら、その数字は「分かった量」ではなくなる。
- **変動報酬**。ランダムに大きな報酬が出る仕組みは、買い切りアプリでは搾取的に見える。
- **連続日数の喪失を煽る演出**。
- **数字が主役になること**。主役は木と「音だけで」の記録。通貨は燃料。
- **学習と無関係な買い物**。倍率が難易度から出る限りこの問題は起きない。
- **総合英語コース、単語帳、英作文の添削**。機械が最初に食べる領域。

ひとつ添えたいこと。これは滞在時間を伸ばす設計であり、
中身が本当に本人のためになっているときだけ正当化される。
経過時間の控えめな表示を入れる。「いつの間にか」が「気づいたら二時間」になったとき、
それを本人に伝えるアプリの方が、買い切りとして信用される。

## 8. 未解決の論点（壁打ちしたいところ）

### 育成の設計

1. 木が持てる実に上限を置くか。上限に達すると実らなくなり、収穫するまで止まる。
   区切りが生まれ戻る理由にもなるが、長いセッションを中断させる。
2. 収穫は手動か自動か。手動なら採る行為そのものが報酬になる。
3. 実は時間で熟すか。熟すと放置に報酬を与えることになる。
   「自分が育てた実だけが、置いておくと少し良くなる」程度なら誠実か。
4. 転生（プレステージ）をどう作るか。案：やり切った分野を**手放す**と、
   “会話”が引退し、枝が木質化して幹に残り、以後の獲得に永続倍率が付く。
   失うのは「もう簡単に正解できる素材」。犠牲が本物なら成立するか。

### 問題形式

5. 一語分岐にすると、AI に求める生成物が変わる。
   言い換えを3つ書かせる代わりに、各台詞の**要となる一語と紛らわしい対**を書かせる。
   生成の質は安定するか。既存の内蔵見本30本をどう移行するか。
6. 「止まらない会話」と「じっくり聞ける形」を両立させるか。
   モードを分けるか、難易度の一部として扱うか。
7. 要旨の設問を残すか、一語分岐に一本化するか。
8. 「ついていけた」をどう測るか。速さそのものを測ると、
   聞き込む前に当てにいく行動を誘発する。
   案：聞き直さず、文字も見ず、短い窓の中で答えたときだけ上乗せ。
9. 純粋な速さを競う場所を別モード（1分ドリル等）に切り出すか。

### 経済

10. 通貨の桁を10倍にする際、既存の残高も10倍に移行すべきか
    （しないと貯めた分が実質目減りする）。
11. 難易度アップグレードの倍率をどう釣り合わせるか。
    上げすぎると簡単な設定に戻す理由がなくなる。
12. 不正解の扱い。罰は要らないが信号は要る。
    案：不正解でも少しだけ入る形にして、手が止まらない感覚を保つ。

### その他

13. 木への「飾り」は一度削除した経緯がある。
    達成したときだけ付く印（音だけで全問正解したときの光る葉など）は、
    買って付ける飾りとは別物として扱ってよいか。
14. 将来のマネタイズ。買い切りを想定しているが、
    価格、無料で試せる範囲、内蔵見本の量をどう決めるか。
15. 「自分宛てでない会話を聞く」形式を、いまのデータ構造にどう載せるか。

## 9. 判断の物差し

迷ったときはこれで決める。

- **機械が代われる能力を鍛えていないか**。読解や翻訳の練習になっていたら方向が違う。
- **その数字は本当に理解した記録か**。待つだけで増えるなら嘘になる。
- **決断の場所を増やしていないか**。決断の場所は、やめる場所。
- **買うと楽になっていないか**。買うと難しくなるのが正しい向き。
- **端末の外に何か出ていないか**。出るのはユーザーがコピーした文だけ。
